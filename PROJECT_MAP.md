# Project map: what is canonical

**Smart Trim & Fuse**: a prototype on synthetic data for AI-assisted trimming and rule-checked fusing of four chip
families (MCU, PMIC, sensor, SoC). It is not production software (see
[`SAFETY_AND_LIMITATIONS.md`](SAFETY_AND_LIMITATIONS.md)).

## Start here

| File | Purpose |
|---|---|
| [`RUN_GUIDE.md`](RUN_GUIDE.md) | Clean install, checks, app, notebooks, submission zip |
| [`RESULTS_SOURCE_OF_TRUTH.md`](RESULTS_SOURCE_OF_TRUTH.md) / [`.csv`](RESULTS_SOURCE_OF_TRUTH.csv) | Every headline number with its dataset, split, seed, model and definition |

## Not part of the submission

`make_submission.py` and `.gitignore` leave these out:

- `.venv/`, `__pycache__/`, `*.pyc`, `.ruff_cache/`, `.vscode/`
- `_archive/`: local backups
- `Colab Notebook/cleaned/`, `Colab Notebook/*.joblib`, `Colab Notebook/evaluation_06.json`: regenerated by the
  notebooks; the canonical models are in `Smart Trim Fuse/models/`
- `Deliverables/Power BI/` and the company's problem statement (`AI Trim & Fuse/*.docx`, `*.pdf`): kept locally, not published
- `Smart Trim Fuse/app/views/archive/`: the older website pages replaced in the redesign, kept locally
